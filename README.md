# DaySetter

DaySetter is a Minecraft plugin that allows players with the appropriate permissions to set the in-game time to day using a simple command. This plugin is designed to enhance gameplay by providing a quick and easy way to manage the in-game time, making it ideal for servers that require frequent time adjustments.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Ensure you have the necessary permissions to use the `/setday` command.
2. In the game, type `/setday` in the chat.
3. The in-game time will be set to day, and a confirmation message will be displayed.
